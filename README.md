# Appu Rathod - Portfolio Website

A modern, professional portfolio showcasing AI/ML projects, full-stack development work, and technical skills.

## Live Portfolio
🔗 https://appurathod-portfolio.vercel.app/ 

## 🚀 Features

- **Responsive Design**: Works perfectly on desktop, tablet, and mobile devices
- **Modern UI**: Dark theme with blue accent colors and smooth animations
- **Typewriter Effect**: Dynamic role switching in the hero section
- **Smooth Scrolling**: Fade-in animations and smooth navigation
- **Project Showcase**: Detailed project cards with stats and tech stacks
- **Skills Display**: Organized by categories (Languages, ML/AI, Frontend, Backend, etc.)
- **Contact Section**: Multiple ways to get in touch

## 🚀 How to Use

1. Open `index.html` in a web browser
2. To add your photo, replace the base64 image in `js/script.js` or add an actual image file
3. Customize content in `index.html`
4. Adjust colors in `css/style.css` by modifying CSS custom properties in `:root`

## 📸 Adding Your Photo

Replace the base64 string in `js/script.js` with your actual photo:

```javascript
document.getElementById('hero-photo').src = 'assets/images/your-photo.jpg';
```
